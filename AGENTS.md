# Agent instructions

This repository keeps shared instructions for all coding agents in
[`CLAUDE.md`](./CLAUDE.md). Read and follow that file before starting work.
Treat its instructions as repository instructions regardless of which agent
or harness you are using.

When working in a subdirectory, also read any `CLAUDE.md` files along the
path from the repository root to that directory. Those instructions apply
to their directory and its descendants; more specific instructions take
precedence over broader ones.

Keep shared instructions in the applicable `CLAUDE.md` file rather than
duplicating them here. This file is the entry point for harnesses that
discover `AGENTS.md`; `CLAUDE.md` remains the source of truth.
